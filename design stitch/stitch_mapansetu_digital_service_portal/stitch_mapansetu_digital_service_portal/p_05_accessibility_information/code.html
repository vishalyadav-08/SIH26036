Accessibility Information

MapanSetu is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards, aligning with GIGW 3.0 guidelines.

accessibility_new Our Approach to Accessibility

keyboard Keyboard Navigation

All interactive elements are fully operable through a keyboard interface. Visible focus indicators (a distinct blue outline) highlight the currently active element to assist sighted keyboard users.

record_voice_over Screen Reader Support

The platform utilizes semantic HTML and ARIA landmarks to ensure compatibility with modern screen readers, providing context and structure to assistive technologies.

text_increase Text Resize

Text can be resized without assistive technology up to 200% without loss of content or functionality. A dedicated tool is provided in the global utility bar.

contrast High Contrast

A high-contrast mode is available, optimizing the color palette to meet strict WCAG AAA contrast ratios for users with visual impairments.

Accessibility Standards

We actively work to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 level AA, and the Guidelines for Indian Government Websites (GIGW 3.0). This compliance ensures the platform is robust, perceivable, operable, and understandable.

WCAG 2.1 AA GIGW 3.0 Compliant WAI-ARIA Enabled

build Using the Utility Bar

Located at the very top of every page, the utility bar provides instant access to accessibility features.

  • A+
    Text Size Adjust Increase or decrease the global font size for better readability.
  • contrast
    Contrast Toggle Switch to a high-contrast color scheme.
  • language
    Language Selection Translate the interface to Hindi or English.

report_problem Encountered an Issue?

If you experience any difficulty accessing information on MapanSetu, please let us know so we can assist you and rectify the issue.
