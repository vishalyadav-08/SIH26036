## User Roles Identified

### 1. Officer (अधिकारी)
- License management
- Verification management
- Complaint-Based Inspection
- Periodical returns review

### 2. Dealer (डीलर)
- Verification (Weights & Measures + NAWI)
- Periodical returns
- License operations

### 3. Manufacturer (निर्माता)
- Periodical returns
- Verification operations

### 4. Repairer (मरम्मतकर्ता)
- Verification (Weights & Measures + NAWI)
- Periodical returns
- Multiple Application at one click

### 5. Citizen/Trader (नागरिक/व्यापारी)
- Verification requests
- License application
- Self-service at office/camp

## Key Features Identified

### Verification Types
1. **Weights & Measures Office/Camp Verification** — Traditional verification at office or camp
2. **NAWI (Non-Automatic Weighing Instruments) - PT (Periodic Testing)** — Electronic scale verification
3. **Tank Lorry Verification** — Tanker measurement verification

### License Operations
- Officer License Management
- Citizen License Application
- License via Nivesh Mitra integration
- License via DigiLocker integration

### Periodical Returns
- Dealer Periodical Return
- Manufacturer Periodical Return
- Repairer Periodical Return
- Officer Periodical Return

### Complaint-Based Inspection
- Officer handles complaint-based inspections

### FPS (Fair Price Shop) - Star Trader System
- FPS rating/grading system

### Incentive Policy 2026
- New incentive policy for department performance
